# Antigravity 2.0

**Antigravity 2.0**은 Google이 밀고 있는 **에이전트 우선(agent-first) 개발 환경**입니다. 데스크톱 앱에서 시각적으로 에이전트·아티팩트를 다루고, **Antigravity CLI(`agy`)** 로 터미널·SSH에서 같은 엔진을 쓸 수 있습니다.

## 구성 요소

| 구성 | 설명 |
|------|------|
| **데스크톱 앱** | 멀티 에이전트·프로젝트·아티팩트 중심 GUI |
| **Antigravity CLI** | `agy` — Gemini CLI 후속(개인/무료 사용자 마이그레이션 대상) |
| **공유 엔진** | CLI ↔ 데스크톱 설정·세션 연동 |
