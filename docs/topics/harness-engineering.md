# Harness Engineering

**Harness Engineering**(하네스 엔지니어링)은 LLM·에이전트를 **반복 가능하게 실험·평가·운영**하기 위해, 프롬프트·도구·데이터·메트릭을 한 덩어리로 묶어 두는 **엔지니어링 방식**을 가리킵니다. 단발성 프롬프트 작성과 달리, **버전·회귀 테스트·관측**을 전제로 합니다.

## 왜 위키에 넣었나

- LLM·에이전트 파이프라인과 함께 읽을 때 **「평가·파이프라인」** 축이 분명해집니다.
- Synapse로 [Antigravity 2.0](/topics/antigravity-2), 마케팅 파이프라인 스토리, 테디노트 허브와 연결합니다.

## 핵심 포인트

| 항목 | 설명 |
|------|------|
| **평가 harness** | 고정 입력·기대 출력으로 모델/프롬프트 변경을 비교 |
| **에이전트 harness** | 도구 호출·멀티스텝 워크플로를 동일 조건에서 재실행 |
| **운영** | 로그, 비용, 실패 케이스를 같은 프레임으로 수집 |
